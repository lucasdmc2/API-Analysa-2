🔧 Guia de Solução de Problemas

1. Port Forwarding SSH:

ssh -L 8000:localhost:8000 usuario@servidor

Depois use: http://localhost:8000

2. Descobrir IP do Servidor:

No servidor, execute: curl ifconfig.me

Depois use: http://IP-DESCOBERTO:8000

3. Verificar se API está rodando:

No servidor: curl http://localhost:8000/health

4. Testar IPs Internos:

Tente os IPs sugeridos acima (172.30.0.2:8000 ou 172.17.0.1:8000)

5. Usar Ngrok (se disponível):

ngrok http 8000 - Gera URL pública
